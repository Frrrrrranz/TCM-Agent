TCM-Agent

让中医药分析
有依据、可追溯。

TCM-Agent 将领域规则、结构化数据库、RAG 检索和可恢复的 Agent 工作流组合起来，为中药、方剂、证候、穴位与医案研究提供辅助分析。

开始使用 查看架构 使用指南

核心能力

领域检索

通过 SQLite 与 ChromaDB 检索中药、方剂、证候、穴位和医案，并把工具依据带回回答。

辨证工作流

结合症状、舌象与脉象生成候选分析，明确证据不足、鉴别方向和需要补充的信息。

安全边界

检查常见配伍禁忌和高风险场景，始终将系统定位为学习与辅助决策工具。

开发验证

npm run check · npm test · pytest tests -q · npm run build

TCM-Agent 仅用于学习、研究和辅助分析，不构成诊断或处方建议。
